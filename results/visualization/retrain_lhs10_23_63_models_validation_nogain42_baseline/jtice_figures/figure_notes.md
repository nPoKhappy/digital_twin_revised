# Validation figure notes

JTICE guide snapshot supplied by the user; verify current journal instructions at submission. Each figure has a separate caption text file. PDFs are vector figures with embedded fonts; PNG files are previews.

All figures show the existing 63 model runs across interpolation and extrapolation (126 distinct model-region coordinates). The three No-Gain runs are repeated in each family panel as a reference. Marker shape identifies training seed; colour identifies the loss weight or target ratio in the corresponding row. AvgRelRMSE uses No-Gain seed 42 as the common baseline in each region. KCI is ANN-reference directional agreement.

The expanded-y figures use a shared piecewise-linear y scale with a change of slope at 1.35; no values were omitted. The linear versions use a common linear y scale. All x axes include KCI = 100%.

The monochrome companion directory contains one figure per family. Each parameter is identified by its panel title rather than colour; marker shape identifies the seed and hollow markers show No-Gain. The same No-Gain points appear in every row for comparison.
